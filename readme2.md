# Plano de Transição para .NET (de PHP para C#)

## 🎯 Objetivo
Sair de 2 anos de backend com PHP e entrar no mercado como desenvolvedor **júnior .NET**, dominando o essencial de:
- C#
- ASP.NET Core Web API
- Entity Framework Core
- Autenticação com JWT
- Arquitetura limpa

---

## 🚨 Antes de pedir demissão (checklist)

- [ ] Reserva financeira (3 a 6 meses de custo de vida)
- [ ] Plano de estudo em mãos
- [ ] Projeto prático no GitHub
- [ ] Currículo e LinkedIn prontos com foco na transição
- [ ] Pelo menos 5 vagas júnior .NET salvas pra aplicar

---

## 🧭 Plano de Estudo: 30 Dias

### Semana 1 – Fundamentos de C#
- Sintaxe básica (condições, loops, funções, etc)
- Classes, interfaces, herança, enums
- Coleções (`List`, `Dictionary`)
- LINQ (Select, Where, First, etc)
- `async` / `await`
- Criar mini apps de console com C#

**Material recomendado**:
- [Documentação oficial C#](https://learn.microsoft.com/en-us/dotnet/csharp/)
- [C# Essentials – YouTube](https://www.youtube.com/watch?v=GhQdlIFylQ8)

---

### Semana 2 – ASP.NET Core + Web API
- Criar API REST com ASP.NET Core
- Rotas, controllers, DTOs
- Swagger para documentação
- HTTP verbs e status codes

**Exercício**: Criar uma API de tarefas com CRUD completo.

**Material**:
- [Documentação oficial Web API](https://learn.microsoft.com/en-us/aspnet/core/web-api/)
- [API com ASP.NET Core – YouTube](https://www.youtube.com/watch?v=fmvcAzHpsk8)

---

### Semana 3 – Entity Framework Core + Banco de Dados
- Code First com migrations
- CRUD com EF Core
- Relacionamentos (1:N, N:N)
- Uso de LINQ com EF
- Conexão com SQL Server ou SQLite

**Material**:
- [EF Core Docs](https://learn.microsoft.com/en-us/ef/core/)
- [EF Core com ASP.NET – YouTube](https://www.youtube.com/watch?v=1aXZQcG2Y6I)

---

### Semana 4 – Autenticação + Projeto final
- Criar autenticação com JWT
- Middleware de autenticação
- Claims e roles
- Separar áreas públicas/privadas da API

**Projeto final sugerido**:
> **Sistema de gestão de produtos**
> - Login com JWT
> - Cadastro e login de usuários
> - CRUD de produtos
> - CRUD de categorias
> - Relacionamento entre usuário e produtos

---
